# 生产部署指南

本文档介绍如何把后台管理系统部署到 Linux 服务器上(Nginx + Uvicorn + SQLite)。前端构建后由 Nginx 托管,后端由 systemd 守护。

## 1. 服务器准备

```bash
# 安装依赖(Linux / Ubuntu / Debian 为例)
sudo apt update
sudo apt install -y nginx python3 python3-venv python3-pip git

# 创建部署目录
sudo mkdir -p /var/www/admin-system
sudo chown -R $USER /var/www/admin-system
```

克隆代码(或用 `scp`/`rsync` 上传):

```bash
cd /var/www/admin-system
git clone https://github.com/lizimu0/admin-system.git .
```

---

## 2. 构建前端

```bash
cd /var/www/admin-system/frontend
npm install

# 如果前后端同域(走 Nginx /api 代理),无需设置 VITE_API_BASE,直接构建:
npm run build
# 如果需要前后端分离部署,先指定后端地址再构建:
# VITE_API_BASE=https://api.your-domain.com npm run build
```

构建产物在 `frontend/dist/`,Nginx 将直接托管该目录。

## 3. 部署后端

### 3.1 安装依赖与配置

```bash
cd /var/www/admin-system/backend
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 生成生产配置(务必修改 SECRET_KEY 与 CORS_ORIGINS)
cp .env.example .env
nano .env
```

`.env` 生产必改项:

```ini
# 生成随机密钥: python3 -c "import secrets; print(secrets.token_urlsafe(48))"
SECRET_KEY=替换为随机生成的密钥
# 允许的前端域名(多个用逗号分隔)
CORS_ORIGINS=https://your-domain.com
# SQLite 文件路径建议用绝对路径
DATABASE_URL=sqlite:////var/www/admin-system/backend/admin.db
```

初始化数据库:

```bash
.venv/bin/python -m app.seed
```

### 3.2 用 systemd 守护后端

创建 `/etc/systemd/system/admin-system.service`:

```ini
[Unit]
Description=Admin System Backend (FastAPI)
After=network.target

[Service]
User=www-data
WorkingDirectory=/var/www/admin-system/backend
ExecStart=/var/www/admin-system/backend/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 4
Restart=always
RestartSec=3
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
```

启动并设为开机自启:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now admin-system
sudo systemctl status admin-system        # 查看状态
sudo journalctl -u admin-system -f        # 查看日志
```

> 说明:后端只监听 `127.0.0.1`,不直接对外暴露,由 Nginx 反向代理 `http://127.0.0.1:8000`。若需更高并发,可用 gunicorn:`gunicorn app.main:app -w 4 -k uvicorn.workers.UvicornWorker -b 127.0.0.1:8000`。

## 4. 配置 Nginx

复制示例并修改:

```bash
cp /var/www/admin-system/deploy/nginx.conf.example /etc/nginx/conf.d/admin-system.conf
nano /etc/nginx/conf.d/admin-system.conf   # 修改 server_name 与 root 路径
```

测试并重载:

```bash
sudo nginx -t
sudo systemctl reload nginx
```

访问 `http://your-domain.com` 即可。`/api` 会自动转发到后端。

---

## 5. 启用 HTTPS

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```

Certbot 会自动改写 Nginx 配置并配置自动续期。续期验证:

```bash
sudo certbot renew --dry-run
```

## 6. 部署清单

- [ ] `SECRET_KEY` 已改为随机密钥(非默认值)
- [ ] `CORS_ORIGINS` 已改为实际域名
- [ ] 数据库为绝对路径,且 `admin.db` 已加入 `.gitignore`
- [ ] Nginx `server_name` 与实际域名一致
- [ ] 后端仅监听 `127.0.0.1`(不暴露公网端口)
- [ ] HTTPS 已启用并验证自动续期
- [ ] 首次部署后删除默认账号 `admin`,或立即修改其密码
- [ ] 定期备份 `admin.db`(SQLite 单文件,直接拷贝即可)
